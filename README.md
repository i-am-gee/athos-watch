# Athos

> 手表只在有人说话时写盘；手机把这些片段变成「我答应了什么」。

名字取自希腊阿索斯山（Άθως）——以静默著称的修道院共同体。这个应用也一样：你说话时它记录，你不说话时它不存在。

## 这是什么

两个端，一条链：

- **Apple Watch**：常开麦克风，但**只有判定有人声时才落盘**。把一整天的环境音变成一堆可回听的片段，一小时 8–9 MB。
- **iPhone**：把片段变成原话，从原话里判断「我答应了什么」——谁答应的、答应到什么程度、后来有没有变。等你确认后写进提醒事项，每周给一次基于实际结果的复盘。

录音这一层解决的是采集成本；手机这一层解决的是判断成本。后者做不好，录音越多越是负担。

具体例子：你说「我周五前把报价发给小李」，两分钟后又改口「改到下周一吧」——理想结果是**同一条待办的日期被更新，两句原话都能回听**，而不是两条重复的待办。说「要不周五发？」时不会直接生成待办，而是先等你确认。

## 快速开始

```bash
cd AthosWatch
make phone      # 手机端：构建 + 装进 iPhone 模拟器 + 截图（首页 / 复盘）
make promises   # 承诺引擎自检：时间解析、改期合并、周复盘，38 项断言
make sim        # 手表端：在模拟器里看界面
make run        # 手表端：跑「门控 → 切段 → 写盘」全链路（合成信号）
make doctor     # 体检：能不能装到手表上，卡在哪一步
```

`make help` 看全部命令。前两条不需要真机，也不需要 Xcode 工程能签名。

## 已验证 / 未验证

**已跑通**：门控算法（合成信号时序 2.28s 开门 / 7.00s 收场）、AAC 分段写盘与解码、MP4 体积压缩、46mm 首屏布局、承诺合并 38 项断言、提醒事项写入并读回、手机端两个页面实机截图、真机目标编译。

**未跑通**：语音转写（整条链唯一的断点，目前喂给承诺引擎的是手写对话）、手表到手机的数据传输、说话人分离、真机安装与续航。

## 注意

- 工程里的 `DEVELOPMENT_TEAM` 与 `PRODUCT_BUNDLE_IDENTIFIER` 是开发者的个人配置。**如果这个仓库要公开，先把这两项换成占位符**，否则别人编译会撞签名。
- 本仓库不含录音文件，`.gitignore` 已排除 `*.m4a` 等音频格式。
