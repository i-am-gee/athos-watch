# Athos

> 只在有人说话时才写盘的 Apple Watch 录音器。全天候采集，静音时段不产生任何文件。

名字取自希腊阿索斯山（Άθως）——以静默著称的修道院共同体。这个应用也一样：你说话时它记录，你不说话时它不存在。

## 这是什么

手表上常开麦克风，但**只有判定有人声时才落盘**。目的是把「一整天的环境音」变成「一堆值得理解的片段」，为后续转写、蒸馏成个人记忆做输入。

核心不是录音，是用门控把无效音频挡在磁盘和云之外。

## 快速开始

```bash
cd AthosWatch
make doctor     # 体检：能不能装到手表上，卡在哪一步
make sim        # 在模拟器里看界面
make run        # 跑「门控 → 切段 → 写盘」全链路（合成信号，不用麦克风）
```

`make help` 看全部命令。

## 已验证 / 未验证

**已跑通**：门控算法（合成信号时序 2.28s 开门 / 7.00s 收场）、AAC 分段写盘与解码、MP4 体积压缩、模拟器端到端链路、46mm 首屏布局、真机目标编译。

**未验证**：真机安装、真机后台续航、真机拾音质量、真机导出（`devicectl` 路径）。这些需要实际戴表跑，脚本和协议已就绪。

## 注意

- 工程里的 `DEVELOPMENT_TEAM` 与 `PRODUCT_BUNDLE_IDENTIFIER` 是开发者的个人配置。**如果这个仓库要公开，先把这两项换成占位符**，否则别人编译会撞签名。
- 本仓库不含录音文件，`.gitignore` 已排除 `*.m4a` 等音频格式。
